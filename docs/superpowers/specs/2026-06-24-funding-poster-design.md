## 목적

진행 중인 텀블벅 펀딩(`tumblbug.com/marikoandyukie`)으로 후원을 유도하는 SNS 세로 포스터를 제작한다. QR 코드를 통해 스캔 즉시 펀딩 페이지로 이동시킨다.

## QR 코드

- 목적지: `https://tumblbug.com/marikoandyukie`
- `qrcode` 라이브러리로 PNG 생성, 밝은(크림/흰) 카드 위 네이비 모듈
- **스캔 정확도 최우선**: 충분한 명암비와 quiet zone(여백) 확보. 과한 스타일링으로 인식률을 떨어뜨리지 않는다.

## 제작 파이프라인

1. `app/poster/` 라우트(또는 standalone HTML 페이지) 구현 — 기존 CSS 토큰/모티프 재사용
   - 언어는 쿼리 파라미터 또는 라우트로 분기 (`?lang=ko` / `?lang=ja`)
   - 뷰포트를 정확히 1080×1350(또는 2배)로 고정
2. QR PNG 생성 후 페이지에 삽입
3. Playwright로 해당 뷰포트 캡처 → PNG 추출 (`deviceScaleFactor`로 2배 해상도)
4. 한국어판/일본어판 2벌 캡처, `_workspace/posters/`에 저장
5. 야경 컷 선정: namsan_69·33·30·44 등 후보를 풀블리드로 렌더해 비교, 어둡고 여백 있는 컷 채택
